# InTheEgg 펫 시스템 리팩토링 계획

## 현재 시스템 분석

### 아키텍처 개요
- **PetController**: 중앙 제어 클래스 (852줄의 거대한 파일)
- **Action 시스템**: IPetAction 인터페이스 기반 행동 관리
- **Controller 시스템**: 각 기능별 세부 컨트롤러 (Movement, Animation, Interaction 등)
- **Manager 시스템**: PetInteractionManager가 펫 간 상호작용 관리

### 주요 문제점

#### 1. 복잡한 상태 관리

#### 2. Action과 Controller의 책임 혼재
- Action이 Controller를 직접 호출
- Controller가 상태를 변경하고 Action이 또 체크
- 순환 의존성과 복잡한 결합

#### 3. 코루틴 관리의 어려움
- 여러 곳에서 StartCoroutine/StopCoroutine 호출
- 중단 시점 제어가 어려움

#### 4. 중복된 조건 체크
- 각 Action의 GetPriority()에서 동일 조건 반복 체크
- Controller에서도 또 체크
- 성능 저하 및 버그 가능성

```csharp
// Controller가 Action의 역할도 수행
public abstract class PetBehaviorController : MonoBehaviour, IPetAction
{
    protected PetController pet;
    
    public abstract float GetPriority();
    public abstract void OnEnter();
    public abstract void OnUpdate();
    public abstract void OnExit();
    
    // Controller 고유 기능
    public abstract void Init(PetController controller);
}

// 예시: EatingController (Action + Controller 통합)
public class PetEatingController : PetBehaviorController
{
    private GameObject targetFood;
    private bool isEating;
    
    public override float GetPriority()
    {
        if (pet.CurrentState == PetState.BeingHeld) return 0f;
        if (isEating || targetFood != null) return 2.0f;
        return pet.hunger >= 70f ? (pet.hunger - 70f) / 30f : 0f;
    }
    
    public override void OnEnter()
    {
        // 음식 찾기 시작
        FindNearbyFood();
    }
    
    public override void OnUpdate()
    {
        if (targetFood != null)
            MoveToFood();
        else
            SearchForFood();
    }
}
```

### Phase 2: 상태 머신 도입

#### 목표
- bool 플래그 지옥 해결
- 명확한 상태 전환 규칙
- 디버깅 용이성

#### 구현 방안
```csharp
public enum PetState
{
    Idle,
    Wandering,
    Eating,
    Sleeping,
    InteractingWithPet,
    InteractingWithEnvironment,
    BeingHeld,
    Selected,
    ClimbingTree,
    InWater,
    Exhausted,
    Gathering
}

public class PetStateMachine
{
    private PetState currentState = PetState.Idle;
    private Dictionary<PetState, HashSet<PetState>> allowedTransitions;
    
    public bool CanTransitionTo(PetState newState)
    {
        return allowedTransitions[currentState].Contains(newState);
    }
    
    public void TransitionTo(PetState newState)
    {
        if (!CanTransitionTo(newState))
        {
            Debug.LogWarning($"Invalid transition: {currentState} -> {newState}");
            return;
        }
        
        var oldState = currentState;
        currentState = newState;
        OnStateChanged?.Invoke(oldState, newState);
    }
}
```

```csharp
public static class PetConditionChecker

    private static Dictionary<PetController, ConditionCache> conditionCache;
    
    public static bool CanEat(PetController pet)
    {
        if (pet.CurrentState == PetState.BeingHeld) return false;
        if (pet.CurrentState == PetState.Exhausted) return false;
        if (pet.CurrentState == PetState.Sleeping) return false;
        return pet.hunger >= 70f;
    }
    
    public static bool CanInteract(PetController pet)
    {
        if (pet.CurrentState == PetState.BeingHeld) return false;
        if (pet.hunger >= 70f || pet.sleepiness >= 70f) return false;
        return true;
    }
}
```

### Phase 5: 코루틴 관리자

#### 목표
- 코루틴 생명주기 관리
- 메모리 누수 방지
- 중단/재시작 로직 단순화

#### 구현 방안
```csharp
public class PetCoroutineManager : MonoBehaviour
{
    private Dictionary<string, Coroutine> runningCoroutines = new();
    
    public void StartManagedCoroutine(string key, IEnumerator coroutine)
    {
        StopManagedCoroutine(key);
        runningCoroutines[key] = StartCoroutine(coroutine);
    }
    
    public void StopManagedCoroutine(string key)
    {
        if (runningCoroutines.TryGetValue(key, out var coroutine))
        {
            if (coroutine != null)
                StopCoroutine(coroutine);
            runningCoroutines.Remove(key);
        }
    }
    
    public void StopAllManagedCoroutines()
    {
        foreach (var coroutine in runningCoroutines.Values)
        {
            if (coroutine != null)
                StopCoroutine(coroutine);
        }
        runningCoroutines.Clear();
    }
}
```
